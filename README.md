# 🚀 DiloFlow — Сучасний Менеджер планування задач (To-Do App)

**DiloFlow** — це веб-додаток для планування задач та управління особистою продуктивністю з підтримкою сповіщень у Telegram та через Email.

---

## 🛠 Технологічний стек

* **Backend:** PHP 8+ (ООП, PDO, Prepared Statements)
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Security & Auth:** XSS sanitation (`htmlspecialchars`), захист від SQL-ін'єкцій, хешування паролів через функцію password_verify(), шифрування тексту задачі, безпечна робота із сесіями
* **Integrations:** Telegram Bot API, PHPMailer (Gmail SMTP / Resend API)
* **PWA:** Підтримка Web App Manifest та Service Worker (можливість інсталяції як мобільний додаток)

---

## 🌟 Основний функціонал

* 🔐 **Авторизація та безпека:** Повноцінна реєстрація, вхід, відновлення пароля та захист персональних даних.
* 📋 **Управління задачами (CRUD):** Створення, редагування, фільтрація (Всі / Активні / Виконані), сортування за дедлайнами та списками.
* 📂 **Списки та категорії:** Групування задач за категоріями (наприклад, "Навчання", "Робота").
* 🔔 **Система сповіщень:**
  * Інтеграція з Telegram-ботом.
  * Надсилання нагадувань про дедлайни на Email.
  * "Функціонал сповіщень у Telegram та Email повністю написаний і працює, але через правила безкоштовного хостингу InfinityFree автоматичний запуск за розкладом вимкнено — перевірка виконується в ручному режимі."
* ℹ️ **Інформаціний блок:** Сторінка "Про проєкт" із Changelog оновлень та форма зворотного зв'язку.
